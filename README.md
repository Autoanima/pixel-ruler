https://autoanima.github.io/pixel-ruler/

「像素尺」是一個網頁小工具,功能是:

選圖:從照片圖庫選一張截圖
拖曳畫框:直接在圖片上用手指拖出一個方框(框內也能整個拖動調整位置)
即時讀出座標:方框對應到圖片的 X、Y 座標,以及寬度、高度,全部換算成像素單位顯示,四個欄位也能直接手動微調(或用 −10/−1/+1/+10 按鈕細調)
一鍵複製:按「複製全部」,把 X: … / Y: … / Width: … / Height: … 這種格式複製到剪貼簿,貼進捷徑的「裁剪影像」動作參數就能用

整個運算都在手機瀏覽器本機完成,圖片不會上傳到任何伺服器，目的是要設定截圖捷徑功能使用。
